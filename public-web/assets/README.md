# Original website artwork

`keeper-sigil.svg` and `dungeon-heart.svg` are original vector artwork created for
KeeperFX-E. They contain no extracted Dungeon Keeper textures, sprites or logos.
The dungeon is assembled from geometric stone tiles, chambers, braziers and a
stylized horned heart. User-provided screenshots informed the palette and mood;
the linked third-party screenshots are not copied into the website or repository.
